## Projects

### [Raindropticon](https://esadkaya.ca/#raindropticon)

A workforce-management system I'm building for a janitorial company. It checks clock-in locations against site boundaries and gives supervisors a way to review completed tasks. The backend uses NestJS and PostgreSQL/PostGIS, with React for the dashboard and React Native for the field app.

### [Park Opticon](https://github.com/Integer-Conversion-Error/Park-Opticon)

A parking app where drivers can share open spots and report nearby enforcement activity. Built with React Native, a Go API, and PostgreSQL/PostGIS. A separate worker handles nearby alerts and retries failed push notifications. The app is still in development.

### [AutoScraper](https://github.com/Integer-Conversion-Error/AutoScraper)

A tool I built to help search for used cars on AutoTrader.ca. It collects listings, applies keyword filters, saves searches, and exports results to CSV. Built with Python, Flask, and Firebase.

### [Note-Splicer](https://github.com/Integer-Conversion-Error/note-splicer)

A tool for organizing and searching personal notes. It indexes notes in ChromaDB and retrieves relevant passages to answer questions through a Streamlit interface.

### [Synthetic vehicle detection](https://github.com/Integer-Conversion-Error/seg-4180-project)

A course project using synthetic images to train vehicle-detection models. The work included image generation, label checking, dataset splits, and YOLO training.
